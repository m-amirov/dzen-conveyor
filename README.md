# Dzen Conveyor — «Люди и время»

Codex-first редакция для полностью автоматической подготовки исследованных статей и иллюстраций для Дзена. На выходе — папка с публикационным пакетом; **в Дзен система ничего не отправляет**.

## Быстрый старт

Откройте репозиторий в Codex и попросите:

> Подготовь следующую статью для «Люди и время» по полному конвейеру. Сохрани все источники, текст, картинки, проверки и публикационный пакет. Не публикуй в Дзен.

Или выберите конкретную тему:

> Подготовь статью «Почему красивые сервизы годами стояли за стеклом?» по полному конвейеру.

`AGENTS.md` задаёт порядок работы, семь навыков находятся в `.agents/skills/`. Все стадии создания текста и иллюстраций автоматические: **собственный черновик пользователя не нужен**.

## Выходные файлы

Каждая статья хранится в `editorial/articles/<slug>/`:

| Файл | Содержимое |
|---|---|
| `brief.md` | Тема, исследовательский вопрос, рубрика, план |
| `sources.md` | Внутренний реестр реально прочитанных источников и ограничений доступа |
| `claims.md` | Внутренние проверенные утверждения с привязкой к источникам |
| `draft.md` | Полностью сгенерированный отредактированный текст без служебных идентификаторов |
| `review.md` | Фактчекинг, стиль, права, блокеры |
| `images/` | 3–4 проверенные разные иллюстрации на статью (обложка + 2–3 внутри текста) и их метаданные |
| `publish.md` | Готовый текст без ссылочного приложения, подписи, предупреждение о политике площадки |
| `manifest.json` | Машинные статусы и provenance |

Проверка готового пакета:

```bash
python3 -m pip install -r requirements.txt
python3 scripts/validate_package.py editorial/articles/<slug>
python3 -m unittest discover -s tests -v
```

Валидатор проверяет наличие и связность доказательств во внутренних реестрах, реально декодирует изображения с Pillow, сверяет **точный утверждённый текст** между маркерами в `publish.md`, исключает служебные ссылки и метки из читательского текста, проверяет **3–4 разные иллюстрации и их размещение в разных разделах**, подписи и видимое предупреждение. Он **не доказывает историческую правдивость автоматически**; содержательный аудит выполняет Codex с реальными источниками.

Проверенный пример полного локального пакета — [`examples/pilot-portrait/`](examples/pilot-portrait/) (тема № 3, западный фотопортрет XIX века; **не опубликовано**). Его можно проверить отдельно:

```bash
python3 scripts/validate_package.py examples/pilot-portrait
```

## Риск платформы

Дзен официально предостерегает от автоматически сгенерированных текстов. Пользователь выбрал полную генерацию сознательно; публикации **могут не соответствовать требованиям площадки или не пройти монетизацию**. Не скрывать происхождение текста. Подробности — [политика](docs/dzen-compliance.md).
