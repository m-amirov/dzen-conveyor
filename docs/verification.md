## Проверка командой

```bash
python3 -m pip install -r requirements.txt
python3 scripts/validate_package.py examples/pilot-portrait
python3 -m unittest discover -s tests -v
git diff --check
```

На первом прогоне пилотного пакета validator завершился с кодом `0`: `PASS: complete structurally verified package: examples/pilot-portrait`.

Независимая код-ревизия воспроизвела ложноположительные PASS при подмене `publish.md`, отсутствии AI-риск-уведомления, нечитаемом файле картинки, недостоверной архивной подписи, отсутствующем anti-slop-отчёте и внешних статусах. На эти случаи добавлены **отрицательные регрессионные тесты**, ужесточён контракт, добавлено декодирование через Pillow.

Повторная ревизия выявила дополнительные обходы через вставку неодобренного абзаца и сокрытие подписей/уведомлений в HTML-комментарии. Контракт требует точного `draft.md` между двумя маркерами; снаружи разрешены только обложка с подписью и AI/platform-disclosure. Исторический прогон до последующих изменений: **37/37 тестов PASS**. С 2026-11-08 добавлены проверки отсутствия служебных ссылок в тексте и 3–4 уникальных изображений на статью (одна обложка плюс 2–3 внутри разных разделов); актуальная проверка выполняется командами выше.

## Границы результатов

- **Structural PASS не равен истине «по кнопке».** Валидатор проверяет поля `accessed`/`evidence`/`scope` и связи тезисов, но не может сам прочитать внешние источники или гарантировать юридическую чистоту; это задача отдельных редакторских стадий, достоверность их отчётов требует наблюдения.
- Художественная ИИ-сцена не служит историческим документом. Встроенный визуальный осмотр не заменяет атрибуцию реального архивного материала.
- Сгенерированный текст может не соответствовать требованиям Дзена. Никакой модерации и проверки монетизации на площадке не было.
- Пилот создан в рабочем сеансе с доступом к поиску и генерации изображений; последующие запуски Codex без этих возможностей должны завершаться конкретным `BLOCKED`, а не имитацией выхода.
- Пилотный файл **не перемещался в** `editorial/articles/`: он находится в `examples/`, чтобы не смешивать тестовые материалы и редакционную очередь для реальной публикации.
