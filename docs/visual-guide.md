# Визуальный язык

Современный документальный журнал с историческими акцентами, без сплошной сепии.

| Цвет | HEX |
|---|---|
| Бумага | `#F3EDE3` |
| Графит | `#2D3032` |
| Терракота | `#A96C50` |
| Серо-синий | `#607782` |
| Пыльный зелёный | `#74836F` |

Одна ясная сцена или вещь на обложке, подлинная фактура и естественный свет. Минимум визуальных символов, никаких надписей внутри AI-изображения. Не имитировать «настоящую редкую архивную фотографию» выдуманной сцены.

**Норма на статью: 3–4 разных изображения, включая обложку.** Одно изображение — обложка перед текстом, ещё 2–3 размещаются **внутри статьи** после смысловых абзацев из разных разделов. Каждое раскрывает собственный факт, предмет или контекст; не повторять обложку и не добавлять декоративную картинку ради числа. В `images/manifest.json` перечислить их в порядке чтения. Внутри статьи Markdown-ссылка на изображение сопровождается точной видимой подписью из манифеста на следующей строке.

1. Создать визуальный бриф: объект, эпоха, одежда, архитектура, композиция, что исключено.
2. Проверить исторические детали по исследованию до генерации.
3. Сгенерировать 3–4 уникальных реальных файла, проверить **каждый** инструментом визуального просмотра.
4. Заполнить `images/manifest.json` для всех файлов: путь, prompt, `kind`, подпись, происхождение, статус проверки, права.
5. Подписи должны описывать конкретную сцену, вещь или исторический контекст **без повторения формул об ИИ, нейросети и генерации**. Для `kind: ai_reconstruction` добавлять «Художественная реконструкция», чтобы не вводить читателя в заблуждение. Для `kind: ai_illustration` можно использовать «Художественная иллюстрация». Происхождение файлов остаётся в `images/manifest.json`, а единое раскрытие происхождения текста **и изображений** — в конце `publish.md`.

Если генератор изображений или просмотр недоступен, зафиксировать `BLOCKED_IMAGES_UNAVAILABLE`. Один текстовый prompt не является готовой иллюстрацией.
